# 异动跟踪清单

用户已确认：默认筛出值得继续跟踪的异动，解释理由与下一步观察点；保留 24 小时回顾。

## 实现

1. 从完整预警窗口与现有 opportunity 缓存筛选最多三个候选，新鲜度、方向延续、成交量和完整度优先，次数只作次要排序。
2. 规则产生状态、两条依据、观察和移出条件，比较上一轮显示新增与降级。证据不足可空缺，不添加行情请求。
3. 每十分钟检查，有实质变化才请求 AI。数值小幅波动只刷新证据，AI 不能改变规则结论。24h 回顾最多每三小时生成一次解释。
4. AI 失败显示本轮规则结果，移除失效候选；过期缓存明确标识，旧版本升级后立即检查。
5. 默认跟踪清单，保留 24h 回顾，显示行情缓存观察时间。
